# Использование ИИ

Решение создано с помощью OpenAI Codex: код сервиса, SQL, тесты, интерфейс, документация и сценарии проверки подготовлены ИИ. Основной агент объединял работу, исправлял замечания и запускал проверки; отдельные агенты занимались storage, интерфейсом/нагрузочным клиентом и независимым архитектурным ревью.

Артефакты не вынесены за пределы сдаваемого проекта:

- [Исходное задание и уточнения](task.md).
- [Промпты делегирования](prompts.md).
- [Ревью архитектуры, принятые решения и источники](architecture-review.md).
- [Storage: промпт, реализация, проверки](storage.md).
- [Интерфейс и нагрузочный клиент](frontend-load.md).
- [Журнал основной работы и исправлений](work-log.md).
- [Исследование хостинга для работающего Go + PostgreSQL demo](hosting-research.md).
- [Опциональный ежедневный demo-опрос на том же backend](demo.md).
- Сгенерированный исходный код, SQL и тесты находятся в обычных каталогах репозитория.
- Фактические результаты команд — в [../evidence](../evidence); снимки работающего интерфейса — в [../screenshots](../screenshots).

Это технический журнал результатов и решений, а не дословный экспорт внутренних рассуждений модели или системного окружения приложения. Настоящие учётные данные и посторонние пользовательские файлы в репозиторий не включены; `.env.example` содержит только публичные демонстрационные значения.

Результаты генерации проверялись тестами и запуском. ИИ не является доказательством производительности: 100 млн голосов за минуту — целевая распределённая нагрузка, а локальный прогон отражает конкретную конфигурацию и методику.
